# HomeMesh 모바일 앱 콘셉트 데모

방마다 설치한 모듈이 관측한 정보를 연결해 가족의 위치와 상황을 보여주는 **모바일 앱 사용 경험** 데모입니다. LG전자 산학협력 수업의 아이디어를 팀원들과 검토하기 위해 만들었습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치, 빌드, 서버, 외부 라이브러리는 필요하지 않습니다. 데스크톱에서는 스마트폰 형태의 프레임으로 보이며, F12 개발자 도구의 모바일 화면(예: 390 × 844)에서도 조작할 수 있습니다.

GitHub Pages에 올릴 때는 `index.html`과 `README.md`를 저장소 루트에 두고 Pages 배포 브랜치의 루트 디렉터리를 선택하면 됩니다. HTML 한 파일에 스타일, 아이콘, 예시 데이터, 동작 코드가 모두 들어 있습니다.

## 화면 구성

1. **초기 설정**: 로봇청소기 지도 / iPhone 공간 스캔 / 수동 구성 중 선택 → 방 이름 확인 → 모듈 배치 → 가족별 얼굴·목소리 시험 → 기상·취침 범위와 생활 선호 설정.
2. **집**: 방별 가족 위치, 온도·습도 예시, 모듈 상태, 최근 판단, 여섯 장면으로 구성된 상호작용 시나리오.
3. **생활 패턴**: 가족별 설정, 24시간 활동 막대, 선호 온도와 야간 조명. 가족 카드를 누르면 시간 범위와 선호를 수정할 수 있습니다.
4. **자동화**: 야간 조명, 휴식 배려, 청소 순서, 귀가 전 준비의 사용 여부와 판단 기준.
5. **가이드**: 방 사이 인계, 가족 간 선호 충돌, 프라이버시 모드, 청소 순서의 생활 예시. `집 화면에서 예시 체험하기`를 누르면 해당 장면으로 이동합니다.
6. **설정**: 모듈 작동 상태, 방별 카메라 프라이버시, 시나리오 초기화와 초기 설정 재시작.

첫 화면의 **“예시 집으로 빠르게 체험하기”**를 누르면 긴 초기 설정을 건너뛸 수 있습니다. `index.html?demo=1`로 열어도 예시 집에서 바로 시작합니다. 다시 설정 과정을 보려면 `설정 → 처음 설정 다시 보기`를 선택하세요. 선택과 선호는 브라우저 `localStorage`에 저장됩니다.

## 팀원 시연 순서 (약 3분)

1. 시작 화면에서 초기 설정의 스캔 방식과 모듈 배치, 얼굴·목소리 시험 화면을 보여줍니다. 빠른 시연은 예시 집으로 시작해도 됩니다.
2. `집` 화면의 **다음 장면**을 눌러 `방 1 → 이동 중 → 거실 확인`을 보여줍니다.
3. 다음 장면에서 민호의 휴식과 지수의 TV 시청이 겹쳐 **TV 제어를 보류**하는 것을 보여줍니다. `왜 이렇게 했나요?`를 누르면 판단 과정을 읽을 수 있습니다.
4. 거실 프라이버시 모드 장면에서 위치가 **미확인**으로 바뀌는 것을 보여줍니다. 이후 주방에서 다시 확인됩니다.
5. `생활 패턴`에서 기상 범위와 야간 조명 선호를 수정하고, `가이드`에서 일상 예시를 엽니다.

## 데모의 범위

- 얼굴·목소리 등록, 인식 결과, 실내 위치, 환경 수치, 로봇청소기 지도, 가전 동작은 **시나리오로 모사**합니다. 실제 카메라·마이크·LiDAR·로봇청소기·LG ThinQ API와 연결하지 않습니다.
- 등록 화면의 “로컬 처리”는 **제안 제품의 설계 원칙**을 설명합니다. 이 HTML에서 독립 하드웨어의 격리 추론이나 개인정보 보안을 검증한 것은 아닙니다.
- 프라이버시 모드에서는 카메라 관측을 중지한 것으로 표현하고, 해당 방을 비어 있다고 단정하지 않습니다. 다른 센서가 없는 상태에서 재실을 계속 알 수 있다고 주장하지 않습니다.
- 활동 막대와 기상·취침 범위는 시각적 사용 예시입니다. 실제 패턴 학습 또는 강화학습 결과가 아닙니다.

## 수정하기

`index.html`의 JavaScript 상단에서 기본 방(`defaultRooms`), 모듈(`defaultModules`), 가족(`defaultPeople`), 여섯 장면(`scenarioSteps`)을 수정할 수 있습니다. 화면은 한 파일의 HTML/CSS/JavaScript로 구성되어 있으며 외부 CDN을 사용하지 않습니다.
